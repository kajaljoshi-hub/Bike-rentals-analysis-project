# Customer Bike Purchase Insights

## Introduction
This project focuses on examining customer bike purchase data to understand market trends and consumer behavior.  
Using Microsoft Excel, the dataset was cleaned, analyzed, and transformed into meaningful visual reports.

---

## Software & Techniques
- Microsoft Excel
- Pivot Table Analysis
- Pivot Chart Visualization
- Data Filtering
- Dashboard Creation

---

## Analysis Process
- Prepared and structured the raw dataset
- Handled missing and duplicate records
- Generated pivot tables for detailed comparison
- Designed visual charts for better understanding
- Evaluated customer demographics and purchasing patterns

---

## Important Observations
- Customers with stable income showed higher bike purchasing activity
- Adult and middle-age groups were major contributors to sales
- Daily travel distance influenced customer buying decisions
- Family-oriented customers displayed greater purchase rates
